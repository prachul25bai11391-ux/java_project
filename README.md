# Currency Converter Application

## Project Overview
This is a simple Java-based Currency Converter application that allows users to convert an amount from one currency to another using predefined exchange rates.

## Features
- Convert amount between multiple currencies
- Console interface
- Predefined exchange rates
- Error handling for invalid inputs

## Technologies Used
- Java SE (JDK 8+)
- IDE (VS Code, IntelliJ, Eclipse)
- Git & GitHub

## Steps to Install & Run
1. Install Java  
2. Clone repo  
3. Compile: `javac CurrencyConverterApp.java`  
4. Run: `java CurrencyConverterApp`

## Testing Instructions
- Try different amounts
- Check conversion outputs
- Try invalid inputs
